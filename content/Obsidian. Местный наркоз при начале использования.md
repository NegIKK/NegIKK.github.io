# Плагины

## Встроенные

- Базы данных
  - Структурируем данные по свойствам, гибко и удобно. Очень похоже на Notion
- Граф
  - Нужная штука. По началу кажется что баловство, но если вести заметки определенным образом то становится круче папок и тегов
- Ежедневные заметки
  - Полезно, если нужна заметка привязанная к дню, можно юзать для дневника или отслеживания тренировок
  - Если заметка на сегодня уже создана, то при активации откроется существующая, а не создастся новая
- Закладки
  - Как в браузере. Закладки на частые страницы
- Палитра команд
  - Обязательная вещь, через нее можно запустить любую команду. Часто может быть нужна если установлены сторонние плагины. По умолчанию открывается на `Ctrl+P`
- Поиск
  - Поиск по всем заметкам. Как может быть не нужно?
- Уникальный идентификатор
  - Основной способ создания новых заметок. Удобный уникальный нейминг и автоматическое вставление шаблона. Минимум нажатий
- Шаблоны
  - База без которой невозможно. Используется как для обычных заметок, так и для сторонних плагинов

## Сторонние

- [Editing Toolbar](https://github.com/pkm-er/obsidian-editing-toolbar)
  - Панель инструментов. Удобно настраивать форматирование
- [Outliner](https://github.com/vslinko/obsidian-outliner)
  - Передвижение пунктов в списке стрелочками
- [Auto Card Link](https://github.com/nekoshita/obsidian-auto-card-link)
  - Вставленная ссылка превращается в симпатичный наглядный блок
  - Можно убрать автоматическое конвертирование в карточку и делать это только из контекстного меню
- [Paste URL into selection](https://github.com/denolehov/obsidian-url-into-selection)
  - Копируем ссылку, выделяем текст в заметке, нажимаем вставить, текст сразу стал гиперссылкой
- [Homepage](https://github.com/mirnovov/obsidian-homepage)
  - Функционал домашней/стартовой страницы
- [Colored Tags](https://github.com/pfrankov/obsidian-colored-tags)
  - Делает теги разноцветными. Должно было быть вшито, по хорошему
- [Fit](https://github.com/joshuakto/fit)
  - Бесплатная синхронизация заметок между устройствами
- [Quartz Syncer](https://github.com/saberzero1/quartz-syncer)
  - Бесплатный способ выгружать свои заметки на свой сайт
- [Global Proxy](https://github.com/windingblack/obsidian-global-proxy)
  - Иногда github плохо работает, а он нужен для плагинов выше, тогда отлично может помочь
- [Lazy Loader](https://github.com/alangrainger/obsidian-lazy-plugins)
  - Позволяет отсортировать порядок и скорость загрузки плагинов. Если обсидиан долго запускается, то скорее всего этот плагин поможет
- [QuickAdd](https://github.com/chhoumann/quickadd)
  - Макросы. Нужен в комбинации с Fit
